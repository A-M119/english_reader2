    品詞：名=名詞 代=代名詞 動=動詞 助=助動詞 形=形容詞 副=副詞 冠=冠詞 前=前置詞 接=接続詞 間=間投詞

    文の成分

    S 主語（主部）

    「〜は／〜が」にあたる部分。名詞・代名詞、またはそのカタマリ（the girl with blue eyes など）がなる。

    V 述語動詞

    「〜する／〜である」にあたる部分。1つの節に必ず1つある。助動詞＋動詞（will go / was reading / had peeped）はまとめて1つの V と考える。

    O 目的語

    「〜を／〜に」にあたる部分。動詞の直後に置かれる名詞・代名詞。

    C 補語

    S や O が「何なのか・どんな状態か」を説明する部分。名詞か形容詞がなる。S = C（She is happy）、O = C（They call him Tom）の関係になる。

    M 修飾語

    なくても文が成り立つ、おまけの情報。副詞や「前置詞＋名詞」（in the room / on Monday）がなる。

    5つの文型
    • 第1文型 SV：Birds fly.
    • 第2文型 SVC：She is happy.（S = C）
    • 第3文型 SVO：I read a book.
    • 第4文型 SVOO：He gave me a book.（OにOを）
    • 第5文型 SVOC：They call him Tom.（O = C）

    TOEICのヒント：文に V がまだ無ければ空欄には動詞が入る。V がすでにあれば、空欄は動詞以外（または節をつなぐ接続詞）。

    品詞の見分け方

    名詞

    役割：人・物・事の名前。主語・目的語・補語になる。

    語尾で見分ける：-tion, -sion, -ment, -ness, -ity, -ance, -ence, -ship, -er / -or / -ist（人）

    置かれる位置：

    • 冠詞・所有格・形容詞の後（the decision, his success）
    • 前置詞の後（for approval）
    • 主語・目的語の位置
    代名詞

    役割：名詞の代わり。形（格）で役割が決まる。

    語尾で見分ける：I / my / me / mine / myself のように、同じ語でも形が変わる

    置かれる位置：

    • 主語の位置 → 主格（they）
    • 名詞の前 → 所有格（their office）
    • 動詞・前置詞の後 → 目的格（them）
    • 「自分で」「自分自身を」→ 再帰代名詞（by themselves）
    動詞

    役割：動作や状態を表す。文の V になる。

    語尾で見分ける：-ize, -ify, -ate, -en（widen など）

    置かれる位置：

    • 主語の後
    • 助動詞・to の後は原形（will expand, to expand）
    助動詞

    役割：動詞の前に置いて意味を足す（can / will / may / must / should）。be・have・do も進行形・完了形・疑問文を作るときは助動詞。

    置かれる位置：

    • 動詞の前。後ろの動詞は必ず原形
    形容詞

    役割：名詞を説明する（どんな？）。

    語尾で見分ける：-ful, -ous, -ive, -able / -ible, -al, -ic, -less, -y

    置かれる位置：

    • 冠詞と名詞の間（a successful plan）
    • be動詞の後（is available）
    • become / seem / remain の後
    • make / keep / find + O + ___（keep the room clean）
    副詞

    役割：名詞以外（動詞・形容詞・副詞・文全体）を説明する。

    語尾で見分ける：形容詞 + -ly（quickly, carefully）。ただし friendly, costly, likely, lovely は -ly でも形容詞なので注意

    置かれる位置：

    • be動詞 + ___ + 過去分詞 / -ing（is carefully designed）
    • 助動詞と動詞の間（will significantly increase）
    • 形容詞の前（extremely high）
    • 文が完成した後（finished the work quickly）
    冠詞

    役割：a / an / the の3つだけ。「この後に名詞が来る」という合図。

    置かれる位置：

    • 名詞（またはその前の形容詞）の前
    • a / an：初めて出る・数えられる単数　the：特定のもの
    前置詞

    役割：名詞の前に置いて、場所・時・手段などを表す（in / on / at / for / with / by / during）。

    置かれる位置：

    • 後ろは名詞（または動名詞 -ing）
    • 前置詞と接続詞の区別がよく問われる：during（前置詞）+ 名詞、while（接続詞）+ 文。despite / although、because of / because も同じ関係
    接続詞

    役割：語と語、文と文をつなぐ。

    置かれる位置：

    • and / but / or / so：同じ種類のもの同士をつなぐ
    • because / although / if / when / while：後ろに S + V の文が続く
    間投詞

    役割：感情や呼びかけを表す（oh / well / wow）。

    置かれる位置：

    • 文頭や文中に単独で置かれる。TOEICではほとんど出ない

    TOEIC品詞問題の早見表

    まず選択肢の語尾で品詞を見分け、次に空欄の前後から入る品詞を決める。

    空欄の位置入る品詞
    the / a / 所有格 + ___ + 前置詞・動詞名詞
    前置詞 + ___名詞（動名詞）
    the / a + ___ + 名詞形容詞
    be動詞 + ___（後ろに何もない・前置詞）形容詞
    be動詞 + ___ + 過去分詞 / -ing副詞
    助動詞 + ___ + 動詞の原形副詞
    ___ + 形容詞副詞
    文が完成した後の ___副詞
    ___ の後ろが S + V の文接続詞
    ___ の後ろが名詞だけ前置詞
